# koi-ashell-builder

Minimal public builder for an unsigned **a-Shell mini** IPA from the official source:

<https://github.com/holzschu/a-shell>

The workflow is manually triggered, uses the verified `a-Shell-mini` target on a standard GitHub-hosted macOS runner, disables code signing, packages `Payload/a-Shell-mini.app`, and uploads `a-Shell-mini-official-unsigned`.

This repository contains no KOI source, database, music, personal information, credentials, or secrets.
